# PRTS 变体实现规格

## 1. 目标

将当前 Amadeus 的一版界面命名为 **PRTS**，保留 Amadeus 的人物/世界线内核和锈蚀材质，登录与主界面改用用户指定的罗德岛 Logo；排版采用明日方舟官方公开页面可观察到的节点式信息架构、窄色条、短横线、状态标签、浅底高对比、冷青/安全橙信号色和可切换主题卡片。

这是“按公开视觉语言做原创转译”的本地实验，不是官方 UI 复刻，也不是官方 PRTS 标识。用户提供的罗德岛 Logo 是单独登记的本地原型例外，不构成公开授权。

## 2. 首屏布局

1. **状态条**：左侧显示 `PRTS / AMADEUS ARCHIVE`，右侧显示连接状态、世界线 ID 和时间戳。
2. **主任务卡**：只出现一个主要动作（继续对话、查看观测日志或接听来电），使用橙色动作条和青色连接点。
3. **档案列**：显示世界线、关系阶段、最近事件和解锁状态；每张卡都可键盘操作。
4. **消息面板**：保留聊天主体，但把“系统状态、人物消息、用户输入”拆成不同层级，不再全部使用同一种暗色文字。
5. **底部记录**：显示版本、素材权利状态和最近一次事件的时间戳。

## 3. Token 初版

```css
:root {
  --prts-paper: #e9e7df;
  --prts-paper-deep: #d8d4c8;
  --prts-graphite: #22292d;
  --prts-graphite-soft: #526067;
  --prts-rust: #b65b33;
  --prts-rust-deep: #7c3f29;
  --prts-signal: #16b8cf;
  --prts-signal-deep: #087b91;
  --prts-warning: #ee8b2d;
  --prts-line: rgba(34, 41, 45, .22);
}
```

使用原则：纸色负责大面积背景；石墨负责正文；锈橙只负责动作、警告和旧铜边缘；冷青只负责连接、选中和可用状态。禁止用接近纯黑的整屏背景表达“锈蚀风”。

## 4. 状态与动效

```text
idle       -> ready       -> active       -> archived
未连接       已就绪          正在处理          已归档
```

- `ready`：冷青短亮，动作条可用。
- `active`：橙色进度条 + 轻微扫描，不持续闪烁。
- `archived`：降低饱和度，保留时间戳和可回放入口。
- `error`：只使用橙/红的窄色条与文本，不用全屏红色遮罩。

## 5. 合规验收

- 除用户提供的罗德岛 Logo 本地原型外，不出现官方明日方舟/PRTS Logo、角色立绘、PV 截图、原作台词或完整页面截图。
- 每个实际参考点都在 `source-manifest.csv` 有链接、用途、权利状态和审核日期。
- PRTS 相关原创图标、纹理和 CSS 进入 `design-reference/arknights-prts/derived/` 或项目自己的源目录，不进入 `material/`。
- 未完成权利审查前，`material/` 和其他官方样本不得放进 `public/`；含罗德岛 Logo 的 `prts-v1` 只能在本机预览，不得进入公网部署或公开发行包。
