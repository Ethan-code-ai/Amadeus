# PRTS / Amadeus 明日方舟视觉参考库

> 建立日期：2026-09-20  
> 用途：为 Amadeus 的 PRTS 变体提供可追溯的公开视觉参考、设计拆解和版权门禁。  
> 定位：研究库，不是官方明日方舟资源包，也不把官方图片复制进网站。

## 1. 本轮调整结论

这套库不再只围绕七周年，也不再用自创的“像明日方舟”的单张概念图代替研究。PRTS 变体的视觉方向改为：**直接观察官方公开页面的版式、信息层级、色彩关系、动效节奏和材质处理，再把规则转译为 Amadeus 自己的终端界面**。

“PRTS”是本项目内部对这一版 Amadeus 变体的名称，不代表官方产品、官方 PRTS 系统或与鹰角网络/Yostar 的合作。原有 Amadeus 资产继续保留，PRTS 只作为独立的变体目录和界面命名层。用户提供的罗德岛 Logo 仅用于 `experiments/prts-v1` 本地原型；公开使用权尚未核实，不得部署或再分发。

## 4. 视觉拆解（用于 PRTS，不是复制清单）

### 4.1 信息结构

- 首屏先给“当前状态/可操作入口”，再给装饰性世界观文案。
- 标题、编号、日期、状态标签和短横线构成稳定的阅读锚点。
- 复杂内容拆成“节点 → 卡片 → 详情”三级，避免把一张海报塞进整个页面。
- 活动样本反复使用“未开放 / 进行中 / 已完成 / 可领取”四态，适合直接迁移到世界线事件。

### 4.2 色彩与材质

- 基底保持浅灰、暖白或低饱和纸色，避免把“锈蚀”误做成整页黑色。
- 信号色只用于状态和交互：冷青用于可用/连接，橙色用于警告/动作，深石墨用于正文。
- 允许锈橙和旧铜出现在边缘、分隔线、噪点和小面积面板，不让锈色覆盖所有背景。
- 纹理只做低对比度叠层：细扫描线、纸张颗粒、金属拉丝、局部氧化斑；文字区域必须保持干净。

### 4.3 组件与动效

- 组件优先使用直角、斜切角、窄色条、短横线和定位标记；不堆叠无意义的六边形。
- 动效遵循“输入 → 确认 → 状态更新 → 记录”四步，时长短、可跳过，减少持续发光。
- 每个卡片都要有可访问的文本状态，不依赖颜色或背景图传达含义。
- 除用户指定的罗德岛 Logo 本地原型外，官方样本中的角色、Logo、图标、台词和原图都不进入项目静态资源。该 Logo 的使用状态为 `private-prototype-unverified`，不是公开发布许可。

## 5. PRTS 变体命名与边界

| 项目 | 规则 |
|---|---|
| 产品显示名 | `PRTS` |
| 辅助识别 | `PRTS / AMADEUS ARCHIVE`，仅作为本项目内部变体标签 |
| 旧版 Amadeus | 保留原命名、原 Logo 和原目录，不重命名、不覆盖 |
| 视觉目标 | 采用官方明日方舟页面的“信息密度 + 状态组件 + 冷暖信号”规律，再叠加 Amadeus 原有的锈蚀材质与神经网络叙事 |
| 本地 Logo | 用户提供的罗德岛官方 Logo，仅用于 `experiments/prts-v1` 本地原型；不表示获得商用或公开传播授权 |
| 禁止事项 | 不使用官方 PRTS 标志、角色立绘、PV 截图、拆包 UI、原作台词或可误认的完整页面复刻 |
| 公开状态 | 目前仅建立本地研究库和本地原型；含罗德岛 Logo 的 `prts-v1` 不得部署、发行或提交公开仓库 |

1. 先按 `PRTS-variant-spec.md` 把当前主界面拆成节点、档案、消息、观测日志四个组件层。

4. 只有获得明确许可或改为完全原创替代后，才允许把图像/字体/Logo 加入 `public/`。
