# Amadeus 注释实验副本：源码阅读说明

这个目录是从正式项目复制出的学习副本。核心业务代码增加了中文解释性注释，正式项目未被修改。

## 推荐阅读顺序

1. `app/page.tsx`：理解浏览器怎样保存消息、发送请求、显示回答和触发语音。
2. `app/api/chat/route.ts`：理解 `/api/chat` 怎样校验消息、切换人设并请求 DeepSeek。
3. `app/LiveCharacter.tsx`：理解 Canvas 人物的呼吸、眨眼、嘴型和鼠标跟随。
4. `app/globals.css`：理解左右分栏、终端配色和响应式布局。
5. `tests/rendered-html.test.mjs`：理解构建后怎样做最基本的自动检查。
6. `vite.config.ts` 与 `scripts/local-server.mjs`：最后再看构建、Cloudflare 模板和本地进程管理。

## 一次聊天的调用路径

```text
用户在 textarea 输入问题
→ page.tsx 的 sendMessage()
→ POST /api/chat
→ route.ts 校验历史与模式
→ 服务端读取 DEEPSEEK_API_KEY
→ 请求 DeepSeek Chat Completions
→ route.ts 返回 JSON
→ page.tsx 追加回答并朗读
→ LiveCharacter 根据 speaking 状态播放嘴部动画
```

## 学习时要特别注意

- `.env.local` 含有真实 API Key，不应复制到实验包、压缩包或 Git 仓库。
- 当前人物是 Canvas 精灵图动画，不是 Cubism Live2D 模型。
- 当前会话只存在浏览器内存中，刷新页面就会消失。
- 当前 API 没有注入实时日期和时间，因此模型不能可靠回答“现在几点”。
- 注释解释的是现有行为，不代表现有实现已经达到生产环境的安全要求。
