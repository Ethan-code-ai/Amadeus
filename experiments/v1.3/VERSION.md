# Amadeus v1.3

基于已保留的 `v1.2-staging` 创建。本版本使用独立目录与浏览器存储键，修改不会回写 v1.2。

## 世界线记忆系统

- 顶部仪表明确标注当前分支，例如 `WORLD LINE: β`。
- 每条世界线都有独立的欢迎语、人物标签和记忆档案；跃迁后，旧助手记录会显示为新档案的重新索引，而不篡改用户输入或伪造新对话。
- `β` 世界线启用 Amadeus 人设与相应记忆：红莉栖的记忆保留在 Amadeus 档案中，时间机器技术仍指向未修正的战争风险。
- `α` 世界线是普通智能助手分支，不加载 Amadeus 人设与记忆。
- 隐藏的 Steins Gate 世界线使用“红莉栖与真由理都活着、悲剧未来已被避开”的记忆语境。
- RAW CHANNEL 不附加任何人物人设或世界线记忆，只返回原始回答。

## 跃迁口令

- `EL PSY KONGROO`：保留 v1.2 的习惯，在 β 世界线与 RAW CHANNEL 之间切换；也能从其他分支回到 β。
- `WORLD LINE ALPHA`：切换为普通助手的 α 世界线。
- `THE CHOICE OF STEINS GATE` 或 `GATE OF STEINER`：切换隐藏的 Steins Gate 世界线；再次输入会回到 β。

任何世界线口令都会触发 1 秒的视觉失真、辉光管滚动，并重新标记聊天档案。

## 实时信息

- 询问“北京时间”“现在几点”时，服务端直接从系统时钟生成可靠的北京时间。
- 询问“北京天气”“东京天气”等问题时，服务端按需调用天气数据源，并将实时观测作为回答上下文。
- 未指定天气地点时，Amadeus 会要求补充城市，不会猜测天气。
- 实时请求和将来的天气服务密钥都只在服务端处理，不会暴露给浏览器。

## Phone Trigger

来电的接听、稍后或拒接仍会使数字在当前世界线的代表偏移率附近变化。它不会跨入另一条主世界线；主世界线仅由口令重构。

## 启动

```bash
npm install
copy .env.example .env.local
npm run dev
```

在本机打开开发服务器提示的地址。没有配置对话服务 Key 时，时间和天气工具仍会在 DEMO 回复中显示已经取得的信息。
