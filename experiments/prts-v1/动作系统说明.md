# v4 帧动画实验说明

本实验版已放弃把当前实现称为 Live2D。人物系统采用“统一锚点的多帧精灵图 + Canvas 连续插值 + 帧间交叉渐变”。

## 12 张过程帧

| 帧 | 用途 |
|---:|---|
| 1 | 默认待机 |
| 2～6 | 眼睛逐渐闭合、完全闭合、逐渐睁开的完整眨眼过程 |
| 7 | 注视和轻微回应 |
| 8～9 | 进入思考、保持思考 |
| 10～12 | 小、中、大三档说话口型 |

## 已增加的互动

- 指针移动：人物轻微注视并平滑跟随；
- 指针进入：切换为专注表情；
- 点击或键盘 Enter/空格：依次轮换“注意回应、短暂惊讶、观察思考”三种反馈；
- 等待回答：先用过渡帧进入思考状态；
- 语音朗读：以两个不同频率混合驱动三档口型；
- 自动眨眼：六帧完整过程，间隔随机；
- 待机动作：小幅呼吸和身体摆动。

## 对齐策略

所有帧使用相同尺寸、相同人物底部锚点和相同绘制高度。素材中约 1～2px 的人物位置差异通过 `FRAME_ALIGNMENT` 表集中校正，代码不再单独覆盖会错位的头部贴片。每次表情变化还会经过 105～145ms 的交叉渐变，从而保留切换中的视觉过程。

## 本地访问

```text
http://127.0.0.1:3001/
```

实验项目没有复制正式项目的 `.env.local`，所以不会复制或泄露 API Key，默认使用 DEMO 回答。若需要测试真实问答，需要在实验目录单独创建 `.env.local` 后重启服务。
