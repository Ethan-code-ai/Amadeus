# PRTS · Amadeus Archive

本版本从 `experiments/v1.4` 独立复制开发；原 `v1.4` 目录保持不变，可作为 Amadeus 原版回退点。PRTS 只是本项目内部的视觉与命名变体，不是官方产品。

## 1. 世界线切换即新对话

所有世界线入口现在共用 `openFreshConversation`：

- 世界线口令先结束当前会话，再向服务端发送只包含该口令的独立请求。
- Phone Trigger 的接听、稍后和拒接会选定目标世界线，并直接创建新聊天。
- 如果服务端判定的世界线与浏览器不一致，界面按服务端结果再次创建干净会话。
- 新会话会取消进行中的请求与语音、清空输入和思考状态、更新偏移率，并只显示目标世界线欢迎语及本次跃迁说明。
- 每次切换递增会话代次；旧请求即使晚到，也无法写入新世界线。

因此，α、β、Steins Gate 之间不再重标旧记录，也不会共享聊天上下文。

## 2. PRTS 平面设计升级

视觉以原作 Amadeus 终端为识别核心，按公开明日方舟页面的结构规律进行原创转译：

- PRTS 变体在登录页与主界面使用用户提供的罗德岛 Logo；原版 Amadeus Logo 仍留在 `experiments/v1.4`，不在本变体首屏显示。该资产仅用于本地原型，未获公开使用许可前不能部署。
- 以骨白氧化金属、铁锈橙、铜褐和低饱和灰绿作为主色；锈蚀由材质、边缘和划痕体现，不再等同于整体低亮度。
- 人物观测区使用中亮度氧化铜褐，通信区使用暖骨白金属，正文与控件均提高对比度。
- `01 / PORTRAIT OBSERVATION`、`02 / COMMUNICATION LOG` 等编号、细网格与少量斜切继续保留，用作现代信息层级而非主视觉。
- 辉光管恢复旧式玻璃管和琥珀发光质感；按钮、面板和弹窗减少过度锐利的战术造型。
- 登录界面把原始 Amadeus 画面作为单一全屏环境，认证信息改为贴边控制带；Logo 不再嵌入独立黑色画框，也取消大面积白色展板和巨型装饰数字。
- 补充适配桌面、平板和手机的断点布局。
- 新增 PRTS 的浅纸色基底、石墨正文、冷青连接色、安全橙动作色和节点/卡片/详情三级层级。
- PRTS 使用独立的 `prts-world-line-v1` 浏览器存储键，不读取或覆盖 Amadeus v1.4 的世界线状态。

## 3. 分享与回归保障

- 新增 1200 × 630 的 v1.4 社交分享封面，并接入 Open Graph 与 X/Twitter 元数据。
- 页面测试更新至 v1.4 文案和新版服务入口。
- API 回归覆盖 β → α 及 α → β 两个口令跃迁方向。

## 4. 保留能力

- α：原始模型通道，不加载人物档案。
- β：Amadeus 红莉栖记忆档案。
- Steins Gate：隐藏的人格分支。
- 按需的北京时间、世界时间和天气信息。
- 动态人物、浏览器语音朗读、Phone Trigger 与世界线噪声动画。
